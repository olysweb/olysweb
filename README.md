## ✨ À propos du projet

**OlysWeb** est un site vitrine conçu pour **présenter les services et les projets** d'OlysWeb. Il permet également de **faciliter la prise de contact**.

Ce projet a été conçu dans le but de proposer un site vitrine moderne, intuitif et facilement maintenable.

---

## 🎯 Objectifs

* Présenter et mettre en valeur les services proposés
* 📖 Présenter les projets réalisés
* 📩 Simplifier la prise de contact avec l'entreprise

---

## 🧠 Approche technique

Ce projet a été développé avec une attention particulière portée à :

* 🔎 La navigation
* 📱 L’accessibilité et le responsive design
* 📈 L'évolution et la maintenabilité

---

## 🛠️ Stack technique

### Frontend

* JavaScript
* HTML5
* CSS3

### API

* Formspree (pour l'envoi sécurisé du formulaire de contact)


### Outils

* Git / GitHub
* VS Code
